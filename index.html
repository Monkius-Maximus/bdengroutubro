Saiba mais

  1. Este simulador foi desenvolvido pelo Núcleo da Seplag com o objetivo de esclarecer dúvidas sobre o atingimento das Metas 2026. Ressalta-se que os resultados apresentados não são oficiais.
  2. Pequenas diferenças podem ocorrer devido a arredondamentos.
  3. As metas foram projetadas considerando o contexto de cada escola e estão descritas no Termo de Compromisso (Escola/GRE/SEE).
  4. O atingimento de cada etapa é calculado pela diferença entre o resultado obtido e a meta estabelecida. A cota do BDE não está considerada neste cálculo. Para consultar o percentual, acesse a aba "Cenário Validado".
  5. Para escolas com mais de uma etapa, o atingimento é calculado de forma ponderada, considerando a quantidade de estudantes em cada etapa.
