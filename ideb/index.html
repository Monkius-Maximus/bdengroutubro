Saiba mais

  1. Este simulador foi desenvolvido pelo Núcleo da Seplag para esclarecer como é calculado o IDEB da escola. Os resultados apresentados não são oficiais: o IDEB oficial é divulgado pelo Inep/MEC.
  2. O IDEB é calculado separadamente para cada etapa (Anos Iniciais, Anos Finais e Ensino Médio). Não existe um IDEB único da escola.
  3. IDEB = N × P. N é o aprendizado: a média das notas de Língua Portuguesa e Matemática no SAEB, convertidas para uma escala de 0 a 10. P é o fluxo: a média harmônica das taxas de aprovação dos anos da etapa, de 0 a 1.
  4. Cada nota é convertida pela fórmula (proficiência − limite inferior) ÷ (limite superior − limite inferior) × 10, com os limites fixados pelo Inep a partir do SAEB 1997.
  5. Na média harmônica, uma taxa de aprovação baixa pesa mais do que uma alta: reprovar em um único ano derruba o fluxo da etapa inteira.
  6. O IDEB é divulgado com uma casa decimal. Pequenas diferenças podem ocorrer devido a arredondamentos.
